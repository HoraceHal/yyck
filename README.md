# 粵語通 · 零基础学粤语

纯静态网页,无需安装。用普通话讲解,目标是能和本地人开口交流。

## 打开方式
- 双击 `public/index.html`(推荐 **Edge** 或 **Chrome**)。
- 或在本文件夹运行 `python -m http.server 5173 --directory public`,访问 http://localhost:5173 。
- 发布到网上:见 [DEPLOY.md](DEPLOY.md)(Cloudflare Workers)。

## 内容
- **新手指南**:粤语是什么、粤拼怎么读、声调记忆法、6 个常见误区、四周计划、跟读四步法、和本地人交流的技巧、FAQ
- **发音入门**:6 个声调(音高曲线)、19 个声母、30 个韵母、声调听辨游戏
- **15 课**(303 词 + 139 句 + 15 段情景对话),分三阶段:
  - 能开口:打招呼 · 听不懂怎么办 · 数字价钱 · 日期时间
  - 能生活:茶餐厅 · 点餐进阶 · 购物 · 交通 · 酒店打车
  - 能交流:家人日常 · 闲聊 · 天气看医生 · 加微信约人 · 地道口语 · 紧急求助
- 每课:学习目标 → 要点 → 本地小贴士 → 词汇 → 句子 → 情景对话(可「我演 A/B」角色扮演)→ 12 道练习
- **复习**:间隔重复(1/3/7/14/30 天)
- **常用句库**:可按普通话/汉字/粤拼搜索全部句子
- **语法速查** + 普通话→粤语常用词对照

## 文件
- `public/` 网站本体(部署时只发布这个目录)
  - `data.js` 发音、语法与第 1 批课程数据;`lessons-extra.js` 新课程与对话;`app.js` 逻辑;`style.css` 样式
- `wrangler.jsonc` / `package.json` Cloudflare 部署配置
- `tools/check-data.js` 数据校验:`node tools/check-data.js`(检查每个汉字与粤拼是否一一对应)
- 加课/加词:在 `lessons-extra.js` 里仿照现有格式添加,然后运行校验。

## 语音说明
发音使用浏览器的语音合成(zh-HK 粤语声音)。没有声音时,见「设置」页的解决办法。

## 自动更新
- 推送到 GitHub `main` → Actions 自动校验并发布到 Cloudflare(见 [DEPLOY.md](DEPLOY.md) 方式 B)。
- 网页每 10 分钟检查 `public/version.json`,有新版本弹出刷新提示;新课在首页带 NEW 标记。
