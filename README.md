# 粵語通 · 零基础学粤语(广州话版)

纯静态网页,无需安装。用普通话讲解,目标是能和广州人(尤其是不懂普通话的长辈)开口交流。

## 打开方式
- 双击 `public/index.html`(推荐 **Edge** 或 **Chrome**)。
- 或在本文件夹运行 `python -m http.server 5173 --directory public`,访问 http://localhost:5173 。
- 发布:推送到 GitHub,Cloudflare 自动构建发布,见 [DEPLOY.md](DEPLOY.md)。

## 内容
- **见家长速成路线**:发音 → 打招呼 → 听不懂怎么办 → 饮早茶 → 见女朋友的妈妈 → 和长辈聊家常 → 语气词
- **28 课**(536 词 + 306 句 + 28 段情景对话),分三阶段:
  - 能开口:打招呼 · 听不懂怎么办 · 数字价钱 · 日期时间 · 高频小词
  - 能生活:茶餐厅 · 点餐进阶 · 饮早茶 · 街市买菜 · 数字时间进阶 · 购物 · 交通 · 广州地名 · 酒店打车 · 电话微信
  - 能融入:见女朋友的妈妈 · 家人日常 · 家里的一天 · 和长辈聊家常 · 长辈叮嘱与健康 · 和女朋友 · 情话进阶 · 节日祝福 · 闲聊 · 看医生 · 加联系方式 · 地道口语 · 紧急求助
- **句型模板(造句机)**:18 个万能框架 × 106 种填空,点一下生成并朗读整句
- **语气词**:呀 啦 喇 咯 㗎 咩 啫 咋 喎 囉 啩 吖 嘅 呢 + 速查表
- **听力实战**:不看字只听一句,选意思(可慢速重听)
- **真人录音 / 跟读对比**:让女朋友录标准音(导出 zip 后由 `tools/import-audio.js` 导入);自己跟读并与标准音对比
- **请女朋友帮我校对**:母语者逐条标 ✔/✘ 并写正确说法,一键复制结果
- **入门友好**:每课有学习目标、要点、易错点、声调颜色图例;词汇带"和普通话对比"注释;点任意粤拼可看拆解(声母+韵母+声调);词库/句库可搜索
- 发音入门(含广州懶音专项)、间隔复习、语法速查、新手指南

## 文件
- `public/` 网站本体(部署只发布这个目录)
  - `data.js` 发音/语法/第 1 批课程;`lessons-extra.js` 第 8–15 课;`lessons-gz.js` 广州专题 + 句型 + 语气词;`lessons-more.js` 第 23–28 课 + 新句型;`notes.js` 词汇注释与易错点
  - `app.js` 逻辑;`style.css` 样式;`version.json` 版本号;`audio/` 真人录音(`manifest.json` 记录)
- `tools/check-data.js` 数据校验:`node tools/check-data.js`
- `tools/build-version.js` 生成版本号(构建时运行,用于"课程已更新"提示)
- `tools/import-audio.js` 导入录音:`node tools/import-audio.js <解压后的文件夹>`
- 加课/加词:在 `lessons-more.js` 里仿照现有格式添加,然后运行校验。

## 说明
- 发音默认用浏览器的语音合成(zh-HK),不是真人;有真人录音的句子会优先播放录音。
- 粤拼和用词由 AI 编写,**未经母语者审核**,请用「校对」页让地道广州人检查。
