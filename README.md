# 粵語通 · 零基础学粤语(广州话版)

纯静态网页,无需安装。用普通话讲解,目标是能和广州人(尤其是不懂普通话的长辈)开口交流。

## 打开方式
- 双击 `public/index.html`(推荐 **Edge** 或 **Chrome**)。
- 或在本文件夹运行 `python -m http.server 5173 --directory public`,访问 http://localhost:5173 。
- 发布:推送到 GitHub,Cloudflare 自动构建发布,见 [DEPLOY.md](DEPLOY.md)。

## 内容
- **见家长速成路线**:发音 → 打招呼 → 听不懂怎么办 → 饮早茶 → 见女朋友的妈妈 → 和长辈聊家常 → 语气词
- **22 课**(430 词 + 224 句 + 22 段情景对话),分三阶段:
  - 能开口:打招呼 · 听不懂怎么办 · 数字价钱 · 日期时间
  - 能生活:茶餐厅 · 点餐进阶 · 广州美食与饮早茶 · 街市买菜与付款 · 购物 · 交通 · 广州地名与出行 · 酒店打车
  - 能融入:见女朋友的妈妈 · 家人日常 · 和长辈聊家常 · 和女朋友 · 节日与祝福 · 闲聊 · 天气看医生 · 加联系方式 · 地道口语 · 紧急求助
- **句型模板(造句机)**:14 个万能框架 × 88 种填空,点一下生成并朗读整句
- **语气词**:呀 啦 喇 咯 㗎 咩 啫 咋 喎 囉 啩 吖 嘅 呢,附"想表达什么用哪个"速查
- **请女朋友帮我校对**:让母语者逐条标 ✔/✘ 并写正确说法,一键复制结果
- **新手指南**:粤拼怎么读、声调记忆法、发音误区、2 周速成/5 周计划、和女朋友妈妈交流实战指南、广州 vs 香港差异
- 发音入门、间隔复习、常用句库(可搜索)、语法速查

## 文件
- `public/` 网站本体(部署只发布这个目录)
  - `data.js` 发音、语法、第 1 批课程;`lessons-extra.js` 第 8–15 课;`lessons-gz.js` 广州专题课程 + 句型模板 + 语气词
  - `app.js` 逻辑;`style.css` 样式;`version.json` 版本号(构建时自动更新)
- `tools/check-data.js` 数据校验:`node tools/check-data.js`(每个汉字与粤拼是否一一对应、句型模板全部组合、地道性提示)
- `tools/build-version.js` 生成版本号,供网页弹出"课程已更新"提示
- 加课/加词:在 `lessons-gz.js` 里仿照现有格式添加,然后运行校验。

## 说明
- 发音用浏览器的语音合成(zh-HK 粤语声音),不是真人。没有声音时见「设置」页。
- 粤拼和用词由 AI 编写,**未经母语者审核**,请用「校对」页让地道广州人检查。
